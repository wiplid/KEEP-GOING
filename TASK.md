# Задание: фронтенд магазина KEEP GOING

Сверстайте магазин по макету и подключите его к API из этого репозитория. Стек — любой: чистый JS, React, Vue. Адаптив обязателен: макет есть для десктопа (1440) и мобилки (375).

Документация по запросам — в [API.md](API.md).

## Уровень 1 — Каталог (обязательно)

- [ ] Шапка: логотип, навигация, `STORE`, `CART (n)` — число берётся из корзины
- [ ] Заголовок `ALL` и кружок с количеством найденных товаров
- [ ] Чипсы категорий из `GET /api/categories`, активный чипс залит чёрным
- [ ] Сетка товаров: картинка, название, цена, зелёная кнопка-стрелка
- [ ] Старая цена зачёркнута, бейдж `NEW`, состояние «Нет в наличии»
- [ ] Поиск с debounce
- [ ] Подвал с формой подписки (`POST /api/newsletter`): успех, ошибка, «уже подписаны»
- [ ] Состояния: загрузка (скелетоны), пустой результат, сервер недоступен

## Уровень 2 — Покупка

- [ ] Страница товара по `slug` в адресе: галерея, выбор размера, количество, «В корзину», похожие товары
- [ ] Нельзя добавить товар с размерами, не выбрав размер
- [ ] Корзина: изменение количества, удаление, итог; `cartId` хранится в `localStorage`
- [ ] Оформление заказа: форма с валидацией, ошибки сервера подсвечивают нужные поля
- [ ] Самовывоз / курьер; блок «Итого» с доставкой (бесплатно от 5000 ₽)
- [ ] Страница «Спасибо» с номером заказа

## Уровень 3 — Со звёздочкой

- [ ] Регистрация, вход, выход; токен в `localStorage`
- [ ] Личный кабинет с историей заказов
- [ ] Сортировка и фильтр по цене; параметры фильтров сохраняются в URL (`?category=bands&sort=price_asc`) — ссылкой можно поделиться
- [ ] Пагинация или «Показать ещё»
- [ ] Оптимистичное обновление корзины (меняем UI сразу, откатываем при ошибке)
- [ ] Проверьте всё с `DELAY_MS=1000` — интерфейс не должен «прыгать»

## Критерии

1. Соответствие макету и адаптив
2. Все данные приходят с API — ничего не захардкожено
3. Обработаны ошибки и пустые состояния
4. Код разбит на модули, запросы к API вынесены в одно место
5. Семантичная вёрстка, работа с клавиатуры (фокус виден, кнопки — это `<button>`)
